## 1. 背景（Background）

Transformer 是现代 AI 中广泛使用的一种神经网络架构，也是许多自然语言处理（NLP）、计算机视觉（CV）、语音、推荐系统以及大语言模型（LLM）背后的核心结构。

Transformer 的核心思想是 **自注意力（Self-Attention）**。自注意力允许序列中的每个 Token 直接与其他 Token 进行交互。与循环神经网络相比，Transformer 可以并行处理多个 Token，因此非常适合使用 GPU 进行加速。

给定一个用矩阵表示的输入序列：

$$
X \in \mathbb{R}^{N \times d}
$$

其中，$N$ 为序列长度（Sequence Length），$d$ 为隐藏维度（Hidden Dimension）。Transformer 首先将输入投影为 Query、Key 和 Value 矩阵：

$$
Q = XW_Q
$$

$$
K = XW_K
$$

$$
V = XW_V
$$

缩放点积注意力（Scaled Dot-Product Attention）的计算方式为：

$$
\text{Attention}(Q, K, V)
=
\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

其中，$d_k$ 为每个注意力头（Attention Head）的维度。缩放因子 $\sqrt{d_k}$ 用于防止点积结果过大，否则可能导致 Softmax 分布出现数值不稳定。

然而，Transformer 的计算开销较大。其主要计算操作包括矩阵乘法、注意力分数计算、Softmax、归一化以及前馈网络（Feed-Forward Layer）等。这些操作的运行效率可能受到以下因素限制：

- GPU 计算吞吐量（Compute Throughput）
- 显存带宽（Memory Bandwidth）
- Cache 使用效率
- Kernel Launch 开销
- Tensor Core 利用率

在本次比赛中，参赛者需要使用 AI 辅助方法，对指定 GPU 型号上的 Transformer 结构运行效率进行优化。优化后的实现需要在保持与参考实现数值结果基本一致的前提下，提高运行性能。

参赛者可以考虑包括但不限于以下优化方法：

- 算子融合（Operator Fusion）
- 内存布局优化（Memory Layout Optimization）
- 低精度计算（Reduced-Precision Computation）
- Tensor Core 加速
- Softmax 优化
- 自定义 CUDA Kernel
- Triton 实现
- TensorFlow 自定义实现
- PyTorch 自定义实现

本赛题的目标，是探索 AI 如何帮助开发者分析 Transformer 工作负载、识别性能瓶颈，并针对特定 GPU 硬件生成更加高效的实现。

## 2. 问题描述（Problem Statement）

- 给定一个固定公式定义的 Transformer Layer，参赛者需要提交一个或多个 GPU Kernel，实现该层的计算，并通过官方提供的测试用例。
- 测试用例将使用 PyTorch 或 TensorFlow 编写。参赛者可以根据需要修改 Layer 的实现方式，也就是说，可以自行决定将 Layer 中哪些部分融合到同一个 Kernel 中执行。
- 测试程序会比较参赛者实现与原始 PyTorch/TensorFlow 实现之间的数值差异。误差必须足够小：
  - 相对误差（Relative Error）< 0.02
  - 绝对误差（Absolute Error）< 0.002
- 测试用例将包含不同输入 Shape，例如：
  - 大 / 小 Batch Size
  - 大 / 小 Sequence Length
  - 大 / 小 Dimension
  - 其他不同维度组合
- 官方会提前告知所有输入 Shape 的组合。参赛者可以在 Layer 实现中加入 Shape 判断，并针对不同 Shape 使用不同的优化实现。
- 鼓励使用 AI 工具，以便参赛者能够在有限时间内针对不同输入 Shape 实现不同的高性能 Kernel。
- 参赛者需要在自己的机器上完成代码优化和测试。由于使用的 GPU 型号可能不同，可以针对自己的 GPU 硬件采用不同的优化方法。
- 需要提供一份清晰的技术报告（Tech Report），其中应详细说明使用了哪些 AI Skills / Tools。对此进行清晰说明可获得额外加分。
